Introdução ao Controle de Versão

Primeiros Passos com Git e GitHub

Aprenda a inicializar seus projetos, controlar as versões do seu código e subir sua atividade para o GitHub para entrega no Teams.

⚙️ Passo 1: Configurar a sua Identidade

Antes de criar qualquer commit no seu computador, você precisa dizer ao Git quem você é. Isso serve para identificar quem escreveu o código nos commits.

# Defina o seu nome de usuário global
git config --global user.name "Seu Nome Completo"

# Defina o seu e-mail institucional ou pessoal
git config --global user.email "seu.email@exemplo.com"

# Verifique se as configurações estão corretas
git config --list

🔮 Passo 2: O Ciclo de Trabalho Local

O Git organiza seu projeto local em três áreas principais: o Diretório de Trabalho (arquivos que você edita), a Área de Preparação (Staging/Index) (onde você prepara as mudanças) e o Repositório Local (onde as versões são gravadas).

☁️ Passo 3: Publicando no GitHub

Depois de fazer seus commits locais, é hora de enviar suas versões para a nuvem. Para isso, crie um repositório vazio no GitHub e execute:

# Associa o repositório local ao repositório remoto no GitHub
git remote add origin https://github.com/seu-usuario/seu-repositorio.git

# Renomeia a branch principal para 'main' (padrão)
git branch -M main

# Envia seus códigos locais para o GitHub (-u define o upstream padrão)
git push -u origin main
Entrega de Atividades

👥 Como Entregar seu Projeto pelo MS Teams

Siga estas diretrizes para fazer a entrega correta do seu projeto de forma limpa e profissional:

1

Não inclua arquivos desnecessários

Sempre adicione um arquivo .gitignore para impedir o upload de pastas temporárias, como node_modules ou pastas de compilação. Isso economiza megabytes de dados desnecessários.

2

Copie o Link do Repositório do GitHub

Vá até a página do seu repositório no GitHub (ex: https://github.com/seu-usuario/seu-projeto) e copie a URL completa na barra de endereço.

3

Anexe a URL no Teams

No MS Teams, entre na tarefa correspondente, clique em Adicionar Trabalho, selecione a opção Link, cole a URL do seu GitHub e clique em Entregar.
